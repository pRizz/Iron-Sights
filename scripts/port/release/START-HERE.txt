IRON SIGHTS - WINDOWS

1. Extract the entire ZIP into a folder you can write to, such as Documents.
   Do not run the executable from inside the ZIP. Keep SDL2.dll next to it.
2. Put your own unmodified GoldenEye 007 USA cart image in the Data folder.
   Supported formats: .z64, .v64, .n64. Extract it first if it is zipped.
   No ROM is included or downloaded by this package.
3. Double-click IronSights.exe. The first launch prepares weapon icons from
   your ROM. A progress window appears; Esc skips preparation and uses names.
   No Python, compiler, administrator access or internet connection is needed
   for icon preparation. Later launches reuse a per-user application-data cache.

Mouse: left click fires, right click aims down sights, Shift sprints.
With the sniper in ADS, the mouse wheel adjusts zoom.

Build details and blue, underlined links are available under:
Options > Gameplay > Iron Sights > System > About / Build Info
The same entry is available on the watch's Iron Sights > System page.

UPDATING
Extract a newer ZIP into the game folder and replace its supplied files.
Keep your Data folder and midas.ini: they contain your ROM, saves and settings.
Suspend points require the same executable and will not load on a newer build.
Normal campaign saves and profiles remain separate.

HD TEXTURES (OPTIONAL)
Iron Sights does not include any HD textures. Get HD Textures in Options (or
Gameplay > Iron Sights > System > HD Textures) downloads intermissionfb's
GoldenEye 007 HD pack, 150 MB, from its makers' GitHub when you choose
Download, into Data/TexturePacks; Remove there deletes it. You can also
download its PNG version (the ...-gliden64-png-hd.zip file) yourself from
https://github.com/GhostlyDark/GoldenEye-007-HD and put the ZIP, or the folder you
extract it to, in Data/TexturePacks. Texture Pack set to HD (the default) draws
its campaign environment textures and the HUD's ammo icons. Any other PNG pack
in Data/TexturePacks (a ZIP or a folder of GOLDENEYE#...png files, such as the
repository's own Code > Download ZIP, which has more textures than the
release, or a pack you are making) is a custom pack: it is used for every
texture it names, ahead of the download, and changes show within seconds. Its
images load in the background, reduced to HD size (at most 8x the original),
so large art appears a moment after a level starts. The weapon and hands in
your view always keep their original look. The 4K and HTS
versions are not read. The hd.istex file that
earlier builds shipped is no longer read; delete it.

SAVE TRANSFER
On the four-campaign Files screen, Export writes a portable JSON backup.
Use Import on desktop or web to load it, then confirm Import and restart.
This replaces all campaigns, profiles, settings and custom controller mappings.
Export the destination's current saves first if you want to keep them.
ROMs, textures and suspend points are not transferred. Each instance needs a ROM.

REQUIREMENTS AND TROUBLESHOOTING
Windows 10/11 on an x86-compatible PC, with an OpenGL 3.3-capable driver.
This is a 32-bit game and also runs on 64-bit Windows.
If icons cannot be prepared, the game remains playable with weapon names.
About shows icon-cache status; Data/Logs/ge_direct.log contains diagnostics.
The executable is not Windows Authenticode-signed. Its GitHub build provenance
is a separate verification mechanism; see VERIFY.txt and the release page.

Downloads: https://github.com/pRizz/Iron-Sights/releases/latest

Windows crash reporting is ON by default. Disable it in Iron Sights > System > Crash
Reporting or in midas.ini: [diagnostics] crash_reporting=0. Reports include
technical system/build/stack information, module paths and an installation ID.
No ROMs, saves, logs or minidumps are attached. See the repository's
scripts/port/crash_reporting.md for payload, queue and privacy details.
