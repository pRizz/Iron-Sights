# Reviewed overlay sites: every place the C sources read a record through another type (LP64-005 Task 3).
#
# `python3 scripts/port/lp64_overlays.py list` prints the sites; `check` requires each to have exactly one
# line here and each line here to match a site. Format, one line a site, fields separated by tabs:
#
#   file:function:kind:text<TAB>VERDICT<TAB>reason
#
# The key is the site as `list` prints it: no line number, whitespace normalized, ` #N` on the Nth
# occurrence of one key in a file. A site whose text changes is a new site and needs a new verdict; its
# old line becomes stale and must be removed.
#
# Kinds (`lp64_overlays.py --help` has the exact patterns): index `((u16 *) x)[n]`; offset, a dereference
# of a pointer cast of a sum (constant or computed offset), of an address or of any other operand (an
# offset of zero), `*(T *) ((u8 *) x + K)`, `*((s32 *) x + 2)`, `*(s32 *) &p->member`, `*(s32 *) p`; opaque `x->padding[84]`; record `(ChrRecord *) p->voidp`;
# run, a Gfx, Model or record member followed by filler members. `list --locals` (stored scalar-pointer
# casts) is a survey aid and has no lines here.
#
# Verdicts:
#   typed       the object is of the type it is read as; for a run, every write and read through the head's
#               address uses the head's type and no more than its bytes (the reason names the writers).
#   same        the layout read is the same at both widths; the reason names the _Static_assert in
#               scripts/port/abi_probe/probe.c or probe_overlays.h that pins it, one that fails if the
#               layout drifts in the way that would make the site wrong.
#   overlay-64  deliberately different at 64 bits, behind IS_64_BIT; the reason names the assertion.
#   dead        not compiled or not reached on PC; the reason says why.
#   defect      the site reads or writes the wrong thing at 64 bits (or at both); the reason starts with
#               its owner, `Task N:` (the task that fixes it), `strict:` (a strict-tier file, fixed on the
#               strict branch) or `undecided:` (not decidable from the code), then what the site means to
#               reach and what it reaches at 32 and at 64 bits, measured with offsetof at both widths.
# `fixed` is not a verdict: a fixed site leaves the list, and its defect line becomes stale and goes with
# it. `check` prints the number of defect lines; `check --no-defects` fails while any remains.
#
# Lines are sorted by key (byte order, `LC_ALL=C sort`).
#
# Task 3's review batches add the lines; the last adds `check` to CI. Batch 1 (the index, opaque and run
# kinds) and batch 2 (the offset kind) are in; the record kind follows.
