# The differences `lp64_equiv.py compare --expect` accepts between builds (LP64-006). Everything not
# listed here must be identical, and a listed difference that is now identical fails too. One line a
# difference:
#
#   PAIR CASE PROFILE STREAM differs-from I explained: CAUSE; removed-by: RUN
#   PAIR CASE PROFILE STREAM differs-from I open: REASON
#   PAIR CASE PROFILE STREAM differs-from I strict: REASON
#   PAIR CASE PROFILE STREAM differs-from I host: REASON
#
# PAIR is the two run folders' names (`i686:a64`), CASE a case of lp64_equiv_cases.py, PROFILE
# `default` or `all`, STREAM `sim`, `gfx` or `snd`, and I the first differing tick, frame or sample.
# `explained` names the cause and the run that matched with it removed (the design's rule);
# `open` is not yet classified; `strict` waits for a fix on lp64/equiv-strict; `host` is seen only
# against the emulated i686 or translated x86_64 build until real x86 hardware confirms it.
#
# An `explained:` line may carry `sha256=HEX` between I and `explained:`, the hash of the newer
# build's normalised stream in a run made with --video, and after it `headless-sha256=HEX`, the same
# for a run made without (Task 17: a headless build's `sim` stream is not its video twin's). The
# difference must then be that stream, not only start at I; `compare` checks the pin of the newer
# folder's kind and judges a line pinned only for the other kind by I alone, with a note (a line
# with no pin is judged so without one). The owner allowed these hashes in this file on
# 2026-11-23; set one only with `lp64_equiv.py pins`, after tracing why the stream changed. The libm
# lines carry none (last exercised in Task 17 Step 2, on real x86).
#
# The Mac's `build/lp64/` trees and folders a line names (its `removed-by:` runs, its measurements)
# were deleted at LP64-006's close (2026-11-24): each line keeps its figures, and each removing run is
# reproduced from the patch and commit `scripts/port/lp64_patches/README.md` gives.
#
# `x64:a64` has no line: Task 14 (2026-11-23) found the two 64-bit builds identical in every judged
# stream of both profiles (x86_64 translated by Rosetta 2, aarch64 native).
